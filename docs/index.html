Tools

Search first. Read second.

Grep and Glob navigate the codebase so the model reads only what matters — the pattern every serious agent converged on.

Grep

Regex content search. Defaults to file lists, with content/count modes, pagination, and ripgrep diagnostics instead of silence.

Glob

File discovery, newest-first, capped at 100 with an explicit truncation flag.

Read · Write · Edit

Surgical file work with pagination and separator-aware path sandboxing.

Bash

Shell with strict allow-list gating, output caps, and Docker/process sandboxing.

WebSearch · WebFetch

Multi-engine research. Fetched pages arrive labelled as untrusted data with SSRF guards.

Memory · Skills · MCP · Browser

Persistent memory, reusable skills, stdio MCP servers, headless browsing.

normalacceptEditsask · fails closedplan · read-onlydeny

Autonomy with guardrails

Runs itself. Can't hurt itself.

Scheduler

Cron-style unattended runs — at, every, cron — with persistent jobs, a run ledger, exponential-backoff retries, timeouts, and overdue-skip on restart.

every 1h · 0 9 * * 1 · at 2026-11-01T09:00Z

Mandate ledger

Human approves one spending mandate — amount range, payee allowlist, daily cap, expiry. Every payment is authorized against it with hash-bound receipts. The model only ever receives approve / deny.

allowlist: [exa] · max $5 · cap $8/day

Safety

Locked down by default.

Token-auth gateway

Remote WebSocket access requires a token; non-localhost binds without one print a loud warning.

Sandboxed shell

Docker or process isolation, command allow-lists, output caps that kill runaway commands.

Injection-aware web

Fetched content is fenced as untrusted data; metadata endpoints that leak cloud credentials are refused.

Audited everything

Budgets with hard stops, approval workflows, and an append-only activity trail.

Honest limits: no SSO/SOC2 yet, ask mode fails closed instead of prompting, shell tools need Unix sh. Full model in SECURITY.md.
