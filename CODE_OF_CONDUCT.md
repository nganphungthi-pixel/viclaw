# Code of Conduct

## Standard

Be direct and technical. Critique code, not people. No harassment, no hate
speech, no sexual content, no doxxing, no spam. Disagreements are settled with
evidence: benchmarks, tests, or docs — not volume.

## Enforcement

Report violations to the maintainer privately. Consequences scale: warning,
temporary interaction ban, permanent ban from the project spaces. The
maintainer's decision is final and will state the reason briefly.

## Scope

Issues, PRs, discussions, and any project chat (Discord/Slack/Telegram
channels if created). This is a small project — the rules are short on purpose.
